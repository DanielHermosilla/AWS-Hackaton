# Panel de cálculo · implementado

Puedes cargar un archivo o crear un ejemplo eligiendo clientes y cargadores.
El signo de interrogación explica el formato. Una tarjeta reúne la flota y sus
supuestos; otra configura tiempo de búsqueda, margen energético, método y semilla.
Si falta algo, el botón explica qué completar. Los JSON rellenan sus valores.

`location-draft` conserva campos y selecciones. El motor administra los núcleos.
