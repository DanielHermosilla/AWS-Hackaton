**OSM es una fuente de datos, no una API gratuita sin límites.** Los datos son ODbL y requieren atribución; publicación de bases derivadas tiene condiciones adicionales, distintas de la licencia del renderer. Los servidores raster y vector públicos tienen políticas propias, disponibilidad de mejor esfuerzo sin garantía y pueden bloquear usos. Raster prohíbe bulk/prefetch y uso offline, exige atribución, identificación/referrer y caché respetuosa. Vector también prohíbe bulk/offline. No descargar sus tiles para preparar la demo. [Licencia OSM](https://www.openstreetmap.org/copyright), [política raster](https://operations.osmfoundation.org/policies/tiles/), [política vector](https://operations.osmfoundation.org/policies/vector/).

**Arquitectura mínima propuesta.**

1. Un componente de MapLibre, una lista/itinerario accesible y selección compartida por ID. Puntos del escenario y rutas de una ejecución se actualizan en fuentes GeoJSON existentes; cámara solo se encuadra al cargar o a pedido. No introducir wrapper React, store global ni capas extra sin necesidad.
2. Contrato pequeño con `scenario_id`, `run_id`, `vehicle_id`, `stop_id`, geometría, procedencia y estado de validación. Si la geometría son segmentos de la red del motor, mantener sus IDs y orden; se puede simplificar para pantalla sin perder el original que valida el motor. GeoJSON usa `[longitud, latitud]`. [RFC 7946](https://www.rfc-editor.org/rfc/rfc7946#section-3.1.1).
3. Tiles/style configurables, con atribución visible del proveedor. API key pública restringida a mapas, dominios y vigencia adecuada; credenciales AWS de servidor nunca van en la UI. Cambiar el fondo no cambia KPIs ni factibilidad. [Keys AWS](https://docs.aws.amazon.com/location/latest/developerguide/using-apikeys.html), [condiciones y fuentes AWS](https://docs.aws.amazon.com/location/latest/developerguide/data-attribution.html).
4. Cuando solo existe una secuencia, dibujo discontinuo rotulado **«Esquema entre paradas; recorrido vial pendiente»**. Si routing externo produce una geometría exploratoria, mostrar su fuente/fecha y **«Geometría calculada aparte; energía no validada sobre este recorrido»**. No hereda sello verde, kilómetros ni balance energético de otra representación.
5. Cargador registrado, compatible configurado y disponibilidad en vivo son estados separados. Error de tiles conserva lista/resultado; error de geometría conserva visitas. Una respuesta antigua se rechaza al cambiar ejecución.

**Offline razonable, como propuesta con cobertura explícita.** Preparar, si la demo requiere desconexión, un paquete regional obtenido de datos/tiles con permiso: un `.pmtiles`, estilo, glyphs, sprites, bibliotecas y geometrías del motor guardados localmente. PMTiles puede leerse directamente con MapLibre mediante su protocolo; sirve un archivo y necesita HTTP Range y CORS adecuados. Comprobar también fuentes/íconos locales; un style local que depende de glyphs remotos no es offline. [PMTiles con MapLibre](https://docs.protomaps.com/pmtiles/maplibre), [protocolo y almacenamiento](https://docs.protomaps.com/pmtiles/).

No descargar un planeta completo ni desplegar un servidor GIS para este respaldo. Si la nueva entrada sale de la cobertura, explicar el límite y ofrecer lista/esquema; no ocultar nodos. La variante más pequeña conserva GeoJSON del motor y datos textuales, sin fondo cartográfico. Puede sostener una presentación local, pero no proporciona routing nuevo offline. Las condiciones offline/caché de AWS, Mapbox, Google o MapTiler **no quedan autorizadas** por esta propuesta; usar datos redistribuibles o un permiso específico.
